# JoyeDrama 统一短剧体验与广告真机测试手册

**适用版本：`JoyeDrama-StartupCheckin-PlayerControls-debug.apk`**
**包名：`com.feather.joyelledrama`**

## 1. 本版验证范围

本版把内容目录与播放体验改为 JoyeDrama 的统一界面。用户不会在正常路径中看到内容来源、SDK、视频服务或授权方名称。短剧内容卡片、海报、标题、集数和语言信息来自短剧 SDK；卡片布局、播放器底部控制、选集、收藏、广告解锁及广告频控由 JoyeDrama 管理。

| 场景 | 预期用户体验 | 内部验证点 |
|---|---|---|
| 启动 | 系统 Logo Splash 后显示 JoyeDrama 深色 Logo 加载页，并立即请求开屏广告；广告关闭、跳过或失败后显示连续签到弹窗，再加载热门短剧。 | 每次 Activity 冷启动均向 Pangle 发起请求；无填充或失败不阻塞签到提示与目录。 |
| 首次启动 | 不再显示“开始追剧”确认框、年龄资格确认或“暂不开启”选项。 | 首次安装默认启用广告请求；可在“我的—广告与隐私”关闭。 |
| 奖励 | 弹窗和底部“奖励”页均展示七日签到格子、今日奖励与广告后领取入口；底部导航使用礼物图标。 | 点击可领取奖励时先请求激励广告；服务离线时广告完成后不伪造金币到账。 |
| 标题栏 | 首页、发现、奖励、我的与播放页均不显示系统 ActionBar 或固定的 `JoyeDrama` 顶部标签。 | Activity 显式使用无标题栏主题；启动品牌页不受此项影响。 |
| 目录 | 双列海报卡片、剧名与集数，不显示固定顶部品牌栏。 | 不展示合作方返回的原始语言代码；封面 URL 加载失败时显示渐变占位。 |
| 播放 | 左上角透明返回按钮回首页；简介默认收起且展开后可滚动阅读全文；进度条和透明控制位于单行，可手动隐藏。 | 视频单击是唯一暂停/继续入口；“选集”为文字按钮；上滑屏幕进入下一集并复用锁集广告解锁流程。 |
| 选集 | 第 1 集免费；第 2 集起显示锁标记。 | 选择锁集应触发 PSSDK 阻断与 `showAdIfNeed`。 |
| 激励解锁 | 用户主动选择锁集后加载广告；完整观看后开始该集。 | 只有 `onUserEarnedReward` 后才调用 `onShortPlayUnlocked()`。 |
| 插屏 | 每集自然结束时尝试插屏。 | Debug 包最短间隔 10 秒；同一集只请求一次；无填充不阻断下一集。 |

## 2. 安装前准备

请先卸载旧版 JoyeDrama，或直接覆盖安装新版。为了验证首次安装默认广告请求和连续签到弹窗，可在 Android 系统的应用详情中执行“清除存储”；这会重置广告偏好、收藏和本地会话解锁状态。

测试设备应使用合作方允许的播放地区网络。目录能加载且播放成功后，广告是否返回素材仍取决于 Pangle 测试广告位、设备网络与广告 SDK 的填充结果；无填充不是播放器故障。

## 3. 推荐测试顺序

### 3.1 启动与隐私

冷启动后，预期依次看到系统 Logo Splash、JoyeDrama Logo 加载页、Pangle 开屏广告（若有可展示素材）、连续签到弹窗和短剧目录。应用不再要求点击确认才请求开屏；每次冷启动均会请求一次。广告关闭、跳过、初始化失败或无填充时，仍必须进入连续签到弹窗和目录。

Pangle 广告页面中的倒计时圆环、跳过/继续进入应用文案、商店跳转卡片与具体广告素材由 Pangle 返回的广告创意决定，应用不会覆盖或仿制该广告页面。JoyeDrama 控制的是广告前的 Logo 加载页和广告关闭后的签到/内容页面。

在目录右上角点击“广告设置”，可查看并关闭或重新启用广告请求状态。

### 3.2 连续签到与奖励页

开屏流程结束后应出现“连续签到奖励”深色弹窗。未签到时，检查七日格子中的今日档位高亮、今日金币数与“看广告签到”入口；点击后应**先请求激励广告**，再在完整观看回调后尝试签到结算。底部导航已从“任务”改为带礼物图标的“奖励”，其中展示相同的七日签到进度和观剧奖励。

无论奖励服务是否已连接，点击签到弹窗或奖励页中可领取的奖励入口都应先请求激励广告。服务无法连接时，广告完成后只显示未结算说明，不得伪造金币到账；服务恢复后可按服务端规则展示动态金额和正式结算结果。

### 3.3 播放器控制

打开首页、发现、奖励和我的页面，确认状态栏下方不再出现白色或深色的系统 `JoyeDrama` 标题栏。打开任意短剧后，验证左上角透明“‹”按钮可回到首页。简介默认折叠，点击“简介”后显示可滚动文本区域，长描述必须能向下滚动阅读完整内容。

视频区域单击是唯一的暂停/继续方式：暂停时画面、声音和自定义进度均应停止；再次单击后继续播放。底部操作中的“选集”必须是文字按钮；控制行不再提供“下一集”图标。选集、倍速、更多、收藏和“隐藏”位于同一行；点击“隐藏”后可通过右下角“显示控制”文字按钮恢复。

从视频区域**向上滑动**应进入下一集。若下一集锁定，必须自动请求激励广告；完整观看后开始下一集。播放开始后，进度条与时间应随 PSSDK 的播放进度变化，拖动进度条后应跳转至对应秒数。倍速可选 `0.75x`、`1.0x`、`1.25x`、`1.5x` 或 `2.0x`。“更多”包含静音、亮度和沉浸式入口；选择沉浸式后，系统状态栏与导航栏应隐藏，向边缘滑动可临时唤出系统栏。

### 3.4 激励广告解锁

打开任意剧集，点击底部“选集”，选择第 2 集或之后的锁集。预期会提示正在加载解锁广告，并展示 Pangle 激励广告。完整观看后，若奖励服务结算成功应显示“解锁成功”并开始对应剧集；若服务暂不可达，也应显示“本次已解锁，奖励未到账”并允许当前会话继续播放。中途关闭则不能解锁。

如果未展示广告，请记录 Toast 中的失败码或原因。常见原因包括：未同意广告、广告位未配置、30 秒激励频控、当前页面被关闭、广告无填充或 SDK 初始化失败。

### 3.5 插屏广告

完整自然播放一集。SDK 的 `onVideoPlayCompleted` 会先尝试插屏；插屏关闭、跳过、无填充或加载失败后，应用自动进入下一集。用户也可在视频区域向上滑动进入下一集。若下一集为锁定集，应用会自动请求激励广告；完整观看广告后解锁并开始下一集。Debug 版本插屏频控为 10 秒，正式版本为 60 秒；同一集只请求一次。

如果看完一集没有插屏，请通过 `adb logcat -s JoyeDramaPlayer PangleAdsManager` 检查以下日志：

```bash
adb logcat -s JoyeDramaPlayer PangleAdsManager
```

| 日志内容 | 含义 | 下一步 |
|---|---|---|
| `插屏触发` | 已收到自然播放断点。 | 等待 SDK 返回展示、跳过或失败状态。 |
| `插屏已展示` | 广告已成功展示。 | 验证关闭广告后剧情可继续。 |
| `插屏跳过：插屏广告频控中` | 处于 10 秒 Debug / 60 秒正式频控。 | 等待后播放下一集。 |
| `插屏跳过：未配置` | 本机构建参数没有插屏广告位。 | 核对本地受控参数。 |
| `插屏加载失败` | Pangle 返回错误码。 | 记录错误码、设备地区、网络、时间，交由广告合作方核对。 |
| `插屏未请求：用户未同意广告` | 用户选择过拒绝广告。 | 在“广告设置”中重新启用。 |

## 4. 关键限制

当前 Pangle 参数是测试参数，必须用真实 Android 设备验证。短剧播放由合作方 PSSDK 和 VOD License 授权；广告填充、奖励回调和地区可用性属于真实环境行为，无法仅通过本地 APK 编译证明。

本版的“第 1 集免费、后续广告解锁”是用于打通测试体验的客户端规则。正式发布前，剧集免费范围、广告解锁资格、用户权益、奖励记录与反作弊应由服务端和内容合同共同决定；客户端不可作为唯一结算或权益依据。
