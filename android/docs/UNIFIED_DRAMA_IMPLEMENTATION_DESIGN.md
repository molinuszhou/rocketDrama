# JoyeDrama 统一短剧体验实现设计

## 目标

当前只有合作方短剧时，用户从启动、目录、详情和播放器都只会看到 JoyeDrama 的统一体验。未来自有剧加入后，只在内部数据层合并，不改变用户的首页信息架构或播放器操作方式。

## 目录页

目录采用深色沉浸背景与暖珊瑚强调色。顶部只保留“热门短剧”、搜索占位入口和刷新动作；列表改为两列海报卡片，每张卡片展示封面、标题、集数、语言、标签与“立即观看”动作。封面通过网络图片缓存加载，失败时使用稳定的渐变占位卡，不将内容来源显示给用户。

## 播放页

播放器仍由 PSSDK 的 `ShortPlayFragment` 承担视频渲染、视频鉴权与进度控制。JoyeDrama 在其外部叠加自有控制层：左上返回；底部展示剧名、当前集数、选集、收藏和下一集；选集使用半透明底部抽屉，以剧集序号显示免费、广告解锁和已解锁状态。用户点选锁集时通过 PSSDK 的 `startPlayIndex` 触发原生权益回调，广告解锁仍由应用自己的 Pangle 管理器执行。

## 广告策略

开屏广告不与年龄确认绑定。首次安装仍须完成广告隐私选择；后续冷启动和从后台恢复时，已同意用户先尝试开屏广告，然后加载内容目录。拒绝广告的用户可以浏览与播放免费集，但锁集界面必须明确告知“广告解锁不可用”。

激励广告只在用户主动点选广告锁定分集时加载，且仅在 Pangle `onUserEarnedReward` 回调后调用 PSSDK 解锁方法。为避免 PSSDK 列表元数据不完整造成锁集逻辑失效，锁定判断以剧目 `total` 集数为主，而不是仅依赖已下发的 `episodes` 列表长度。

插屏广告只在 `onVideoPlayCompleted` 自然剧集断点触发；为提高真机可观察性，测试构建会记录“触发、频控跳过、广告位未配置、加载失败、已展示”五类状态。广告无填充或失败时不得阻断自动播放下一集。

## 交互状态

| 状态 | 用户界面 | 内部处理 |
|---|---|---|
| 首次启动 | 广告与隐私选择，再进入目录。 | 同意后初始化 Pangle；不显示年龄资格弹窗。 |
| 已同意后启动 | 尝试开屏广告，关闭或失败后进入目录。 | 遵守 6 小时频控。 |
| 选择免费集 | 直接在 PSSDK Fragment 中播放。 | 调用 `startPlayIndex`。 |
| 选择锁集 | 展示“观看广告解锁本集”状态。 | PSSDK 阻断回调中请求激励广告。 |
| 自然播放结束 | 保持剧情连续性。 | 记录插屏触发；频控允许时请求插屏。 |
| 广告失败 | 显示简洁说明，不锁死页面。 | 日志记录 Pangle 错误码和失败阶段。 |

## 合规边界

不复制红果或其他竞品的名称、图标、截图和品牌资产。激励广告属于用户主动的解锁行为；开屏/插屏不授予权益。PSSDK 仍会收到合作方要求的受众资格标记；正式发布前应按目标地区的内容分级、年龄门槛与隐私政策配置，而不是仅依赖客户端判断。
