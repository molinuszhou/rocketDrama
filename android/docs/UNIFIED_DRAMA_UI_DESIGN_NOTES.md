# 统一短剧体验设计准则

## 设计定位

JoyeDrama 对用户只呈现一个短剧内容库。内容来源、SDK、视频托管商和广告平台均是内部实现细节，不在首页、剧集卡片、详情页或播放器的可见文案中出现。

## 公开产品参考提炼

参考公开商店介绍的短剧产品通用能力，优先实现以下体验：竖屏优先的沉浸式播放；从播放器可直接返回内容流；快速选集；收藏/追剧入口；倍速或辅助控制；以及在剧情断点提供明确、可选的广告解锁。公开介绍将“任意选集”“小窗播放”“倍速播放”等视为短剧播控能力，但本轮只实现与当前 PSSDK 兼容的返回、选集和广告解锁外壳，不伪造尚无 SDK 控制能力的功能。

## 本轮信息架构

| 页面 | 用户可见内容 | 隐藏的内部细节 |
|---|---|---|
| 启动 | 开屏广告（用户已授权时）后进入内容流。 | 广告 SDK、广告位。 |
| 首页 | “热门短剧”、筛选标签、海报卡片、剧名、集数、语言和继续观看提示。 | 内容来源、内容提供商。 |
| 播放页 | 返回、剧名、当前集数、选集、下一集、广告解锁、收藏。 | PSSDK Fragment、VOD、License。 |
| 锁集 | 明确说明“观看广告解锁本集”，由用户主动触发。 | 奖励广告回调和权益桥接。 |

## 视觉基调

采用深色沉浸式底色、暖珊瑚/橙红强调色、圆角海报卡片、底部弹层选集与大触控目标。页面层级以剧情内容和当前播放为第一优先级，广告操作仅在用户主动解锁或自然剧集断点时出现。

## 不能照搬的内容

不复制红果或其他竞品的名称、图标、截图、具体文案、品牌色组合、布局像素细节或专有资产；仅借鉴其公开可观察的短剧交互模式。
