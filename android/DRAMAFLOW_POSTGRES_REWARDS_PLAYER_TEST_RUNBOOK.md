# DramaFlow：独立 PostgreSQL 积分服务与播放器回归测试手册

**适用 APK：`com.dramaflow.app` Debug 测试包**
**适用环境：Windows 自有剧内容服务 + Windows Docker Desktop PostgreSQL 积分服务 + Android 真机**

本版 Android 应用连接两个独立服务。它们不能混用端口：短剧内容服务负责目录和视频，积分服务负责宝石、广告事件、签到、每日宝箱、十轮领奖、成就和插屏频控。

| 服务 | 默认端口 | App 设置路径 | 作用 |
|---|---:|---|---|
| 自有短剧内容服务 | `8000` | 我的 → 局域网内容服务 | 片单、封面、分集、播放会话、内容解锁 |
| PostgreSQL 积分服务 | `8100` | 我的 → 积分与奖励服务 | 广告账本、宝石、钱包、签到、宝箱、轮次、成就、插屏 |

## 1. Windows 启动顺序

先启动已有的自有短剧内容服务，确认电脑浏览器可打开 `http://localhost:8000/health`。再按照积分服务包的 `WINDOWS_POSTGRES_REWARDS_DEPLOYMENT.md` 启动 Docker Compose，确认：

```powershell
Invoke-RestMethod http://localhost:8100/health
```

两项健康检查均成功后，以管理员 PowerShell 为 Windows 防火墙放行 TCP `8000` 和 TCP `8100` 的 Private 网络入站连接。手机与电脑必须连接同一个 Wi-Fi。使用 `ipconfig` 找到电脑 Wi-Fi/以太网 IPv4，例如 `192.168.1.25`。

## 2. Android 地址设置

如果首页提示内容服务连接失败，直接使用错误页的 **设置服务器地址**。内容目录加载成功后，再进入：

> 我的 → 积分与奖励服务

输入：

```text
http://192.168.1.25:8100
```

短剧内容地址则应为：

```text
http://192.168.1.25:8000
```

不要在任一字段填写 `127.0.0.1`、`localhost`、电脑名或 VPN 地址；这些地址对 Android 真机不可达。

## 3. 广告与积分验收

开发测试使用 Pangle Waterfall 竖版广告位。实际素材、倒计时、关闭行为和填充结果由 Pangle 下发，应用只在合适时机请求广告并在全屏广告期间暂停 Media3 视频。

| 验收编号 | 操作 | 预期结果 |
|---|---|---|
| R-01 | 打开“奖励”页面 | 能显示宝石余额、现金钱包、连续签到、每日宝箱、十轮奖励和皇冠之路。 |
| R-02 | 点击“立即签到” | 基础签到由数据库结算；当天已签到后才显示“看广告翻倍”。 |
| R-03 | 看完签到翻倍广告 | 广告关闭后，独立服务只允许当日一次翻倍，余额刷新。 |
| R-04 | 签到后点击每日宝箱 | 完整观看一条激励广告后领取一次宝石；当天不可重复。 |
| R-05 | 播放第 1–3 集 | 不请求集间激励广告，且不会写入集间通行奖励。 |
| R-06 | 播放第 4 集及以后锁集 | 原视频先暂停；激励广告完整观看并关闭后，先写入奖励服务、再请求内容服务解锁、最后播放新集。 |
| R-07 | 完整看完已通行的锁集 | 独立服务完成一轮有效观看；宝石按规则自动入账。 |
| R-08 | 达到第 10 轮 | 页面显示“广告后领取”；完成后显示一次“广告翻倍”。 |
| R-09 | 在第 4 集后持续播放 | 服务端冷却时间到后请求插屏；插屏结束后仅当广告进入前正在播放时才恢复视频。 |
| R-10 | 点击视频区域暂停 | 视频画面、声音、进度全部停止；退到后台后不会自动续播。 |

## 4. 播放器与内容回归

| 验收编号 | 操作 | 预期结果 |
|---|---|---|
| P-01 | 选集 | 选集弹层可上下滚动，所有分集可见。 |
| P-02 | 选到后续锁集 | 老集在广告开始前暂停；不会出现广告覆盖视频但仍有剧情声音。 |
| P-03 | 选中第 9 集并播放结束 | 自动进入下一集；如锁定则串行请求激励广告，避免广告与视频并播。 |
| P-04 | 不触碰屏幕持续观看 | 屏幕保持常亮；暂停、退出播放器或进入后台后恢复系统原有休眠策略。 |
| P-05 | 播放失败后进入“更多” | 可选择“重新加载本集”；进度条在播放器未就绪时不会继续执行无效跳转。 |
| P-06 | 查看剧集列表封面 | JSON 中的绝对 URL 和 `/...`、相对路径封面均按当前内容服务地址解析。 |

## 5. 开发与生产边界

开发阶段允许独立积分服务使用 `ALLOW_DEBUG_AD_PROOF=true` 接收 Debug APK 的测试广告证明。生产上架前必须关闭该开关，部署 Pangle 服务端回调/验签，并配置服务端密钥。客户端不能成为正式奖励到账的唯一依据。

现金钱包当前仅透明展示按累计宝石换算出的金额和提现资格预检。它不创建真实打款、也不承诺提现成功；开放提现前必须接入合规支付、身份校验、反作弊、审核、风控与客服流程。
