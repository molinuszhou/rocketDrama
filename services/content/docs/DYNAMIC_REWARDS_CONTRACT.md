# JoyeDrama 轻量动态激励配置与权益结算契约

## 目标

本契约为现有 FastAPI 内容服务增加可运行的轻量运营配置能力。运营人员可更新规则 JSON 并通过受保护管理接口立即生效；Android 仅拉取并展示服务端确认的配置、任务状态、钱包与权益结果。客户端不得自行决定金币、现金、任务完成、锁集解锁或提现资格。

## 运行与存储

| 数据 | 开发/测试实现 | 生产替换方向 |
|---|---|---|
| 运营规则 | 版本化 `reward_rules.json`，原子写入。 | 数据库版本表或受权限控制的运营后台。 |
| 用户钱包/权益/流水 | SQLite，使用事务、唯一幂等键和不可变流水行。 | MySQL/PostgreSQL 等托管数据库，加入备份、审计与分区。 |
| 管理权限 | `ADMIN_CONFIG_TOKEN` Bearer Token；缺失时管理写接口不可用。 | 登录、角色、MFA、审计日志与密钥轮换。 |
| 广告奖励证明 | 仅在 `development` 接收测试证明。 | Pangle 服务端回调/验签，或由受信广告服务生成服务器令牌。 |

## 客户端 API

### `GET /v1/rewards/bootstrap`

输入：`user_id`、`region`、`app_version`（可选）。

返回：规则版本、功能开关、解锁规则、广告频控提示、任务清单及状态、签到状态、钱包、圆环/等级进度、提现/兑换资格、最近权益流水和用户可见文案。客户端应缓存最后一次成功响应，并标记其规则版本；网络失败时不得凭空发放新奖励。

### `POST /v1/rewards/events`

输入：`event_id`（UUID，幂等键）、`user_id`、事件类型、事件发生时间、上下文。当前默认规则只接受完成一集的有效观看事件，并仅以**已完成剧集数**更新任务进度；广告观看次数不会生成任务进度或可领取奖励。生产环境应使用服务端可验证的播放心跳或 CDN/VOD 观看事件，而不是仅信任客户端时长。

### `POST /v1/rewards/ad-claims`

输入：`request_id`（幂等键）、`user_id`、`purpose`（`episode_unlock`、`task_double`、`checkin_double`）、目标对象、广告完成证明。

返回：是否已验证、广告权益令牌、令牌有效期及可继续执行的操作。开发环境仅接受显式的测试证明；生产环境拒绝客户端伪造证明，等待 Pangle 服务端回调/验签接入。

### `POST /v1/rewards/claims`

输入：`claim_id`（幂等键）、`user_id`、`claim_type`（任务/签到/圆环）、`target_id`、领取模式（普通/广告翻倍）、可选广告权益令牌。

服务端事务性检查规则版本、可领取状态、每日次数、广告令牌与过期时间，写入不可变账本后返回最新钱包、任务状态与用户提示。

### `GET /v1/rewards/ledger`

返回用户最近奖励和扣减流水，供钱包与客服排查使用。金额、币种、来源、规则版本、创建时间和幂等 ID 均可审计。

## 管理 API

| 接口 | 权限 | 作用 |
|---|---|---|
| `GET /v1/admin/rewards/config` | Bearer 管理令牌 | 读取当前规则与版本。 |
| `PUT /v1/admin/rewards/config` | Bearer 管理令牌 | 校验、版本递增、原子保存完整规则。 |
| `POST /v1/admin/rewards/config/reload` | Bearer 管理令牌 | 从规则文件重新加载，便于容器挂载配置时使用。 |

管理接口不返回钱包、广告证明、用户设备标识等无关隐私数据。默认不开放跨域管理写操作。

## 规则模型

规则包含：启用开关、UI 文案、默认免费集数、每次广告可解锁集数、每日解锁上限、**有效剧集观看**任务定义/目标/奖励、任务/签到的可选广告翻倍、签到序列、有效观看最小时长、钱包展示与兑换资格和广告冷却提示。当前默认模板关闭分钟圆环，且不提供“观看广告次数领奖”任务。所有数值需保证可解释、可达成并适配内容合同与适用法律。

## 关键安全边界

1. 广告 SDK 的 `onUserEarnedReward` 只能触发“请求服务端验证”；不能直接在 Android 增加余额或永久解锁。
2. 规则版本写入每笔账本，便于回溯一次奖励由何种规则产生。
3. 每个客户端事件、广告领取和奖励领取均使用服务端唯一约束实现幂等，网络重试不会重复发奖。
4. 现金、提现、兑换和支付渠道属于高风险域：本轮只实现显示资格和不可变奖励账本，不实现向任何支付渠道提交或转移资金。
5. 测试证明只能在开发环境开启；生产环境缺少广告服务端验证时，广告翻倍与广告解锁必须失败关闭而非乐观发奖。
